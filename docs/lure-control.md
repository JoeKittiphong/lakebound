# จอยควบคุมเหยื่อและรอก — 29 ตุลาคม 2026

## แบบที่ใช้และลำดับงาน

ใช้ชุดรอก 3D และแถบแรงตึงเดิม เพิ่มจอยทางขวา โดยเลื่อนภาพรอกไปซ้าย 200 logical px และคงขนาดจอย 184 × 184 เดิม แถบแรงตึงยังอยู่ซ้ายของรอก ข้อมูลสายอยู่เหนือรอก ปุ่มมองรอบตัวขยับไปซ้ายของแถบแรงตึงเพื่อไม่บังมือหมุน จอยเล็งก่อนเหวี่ยงยังอยู่ตำแหน่งเดิม

ลำดับที่ดำเนินการ: แยกภาพรอกจากจอย → เพิ่มอินพุตเหยื่อ → อ่านจังหวะ → เชื่อมโบนัสกับการตรวจพบเหยื่อ → เพิ่มผลการหักคันต่อเส้นทางปลา → ตรวจสัมผัสและภาพหลายสัดส่วน → ตรวจระบบตกปลาและบทสอนเดิม

## วิธีเล่น

| อินพุต | เหยื่อปลอมในน้ำ | วัดเบ็ด / สู้ปลา |
| --- | --- | --- |
| ขึ้น | กระตุกเมื่อเข้าทิศทางหนึ่งครั้ง | ผ่อนสายระหว่างสู้ |
| ลง | กรอสายตามระยะโยก | วัดเบ็ด / เก็บสาย |
| ซ้าย / ขวา | สะบัดเหยื่อจริงด้านข้าง | หักคัน เปลี่ยนเส้นทางปลาและแรงตึง |
| ทแยง | กรอพร้อมควบคุมด้านข้าง; ทิศหลักใช้ตรวจจังหวะ | คุมคันพร้อมเก็บหรือผ่อนสาย |
| ปล่อยกลาง | หยุดออกคำสั่ง เหยื่อลอย/จมตามชนิด | หยุดกรอด้วยมือ เบรกยังทำงาน |

จอยมี dead zone และ hysteresis สำหรับการเปลี่ยนทิศ การค้างขึ้นหรือซ้ายขวาไม่สร้างการกระตุกซ้ำทุกเฟรม ผู้เล่นต้องปล่อยนิ้วก่อนเริ่มคำสั่งในสถานะใหม่ โดยเฉพาะจากเล่นเหยื่อ → ปลากัด → สู้ปลา ป้องกันการวัดเบ็ดหรือปล่อยสายโดยไม่ตั้งใจ กลับจากเมนูหรือแอปเสียโฟกัสจะล้างคำสั่งและประวัติจังหวะ

คีย์บอร์ดเดิม: I กรอสาย, K ผ่อนสาย (กระตุกเมื่อใช้เหยื่อ), J/L ซ้ายขวา; E ยังใช้เส้นทางแอคชั่นแบบเดิมได้ แต่ซ่อนปุ่มแอคชั่นแยกบนมือถือ รอกไม่หมุนปล่อยสายเมื่อสั่งกระตุกเหยื่อขึ้น ระหว่างสู้ สปูลปล่อยสายเมื่อเบรกลื่นได้แม้มือหมุนกำลังกรอ

## จังหวะรุ่นแรก

อัปเดตล่าสุด: เพิ่มประกาศจับจังหวะและเงื่อนไขให้ปลาตามก่อนกัด ดู [lure-rhythm.md](lure-rhythm.md) ผลจังหวะอิสระด้านล่างช่วยดึงความสนใจ แต่สิทธิ์กัดของเหยื่อปลอมต้องผ่านสูตรที่ประกาศในระบบใหม่

- **Walk the Dog:** ซ้าย–ขวาสลับ 4 ครั้ง แต่ละช่วง 0.18–0.85 วินาที ใช้กับกบและเหยื่อผิวน้ำ
- **Stop & Go:** กรออย่างน้อย 0.35 วินาที แล้วหยุดอย่างน้อย 0.28 วินาที ทำสองรอบ ใช้กับมินโนว์ เหยื่อยาง และใบหมุน การแตะสั้นหลายครั้งไม่สะสมเป็นการกรอค้าง
- ใช้สูตรที่ตั้งไว้ในเหยื่อเท่านั้นจึงได้โบนัส การกดผิดยังเคลื่อนเหยื่อตามมือ
- เมื่อสำเร็จ เพิ่มระยะตรวจพบเหยื่อไม่เกิน 20% และค่อย ๆ หมดภายใน 4 วินาที ไม่เพิ่มซ้อน ไม่ข้ามเงื่อนไขชนิดเหยื่อ ความลึก ความหิว หรือความระวังของปลา และไม่รับประกันการกัด
- แสดงสูตร/ความคืบหน้าเหนือจอย ตอนสู้ปลาเปลี่ยนเป็นคำใบ้ทิศปลา ไม่มี XP หรือการเปลี่ยนระบบปลดล็อกอุปกรณ์ในงานนี้

## เปิดแก้ใน Godot

- `features/fishing/fishing_hud.tscn`: ตำแหน่งจอย แถบแรงตึง ข้อมูลสาย คำใบ้ ปุ่มมองรอบตัว
- `features/fishing/ui/rod_control.tscn`: ภาพรอกอยู่ซ้ายของ Base/Knob และมีลูกศรสี่ทิศที่บันทึกเป็น Label ในซีน
- `features/fishing/default_fishing_tuning.tres`: กลุ่ม Lure control ปรับ threshold, ช่วงจังหวะ, เวลาหยุด, ระยะสะบัดและกระตุก; กลุ่ม Fight ปรับ rod_steer_strength
- `data/equipment/*.tres`: motion และ lure_pattern ของเหยื่อแต่ละชิ้น
- `features/fishing/lure_gestures.gd`: ตัวอ่านจังหวะแบบข้อมูลล้วน ไม่สร้าง UI หรือ Autoload เพิ่ม

ข้อจำกัด: ยังไม่ได้ทดสอบสัมผัสบนโทรศัพท์จริง เนื่องจากไม่พบ SDK/ADB ที่ใช้งานได้หรืออุปกรณ์ที่เชื่อมต่อ จึงยังยืนยันความถนัดนิ้ว รอยบากจริง ประสิทธิภาพ ความร้อน และแบตเตอรี่บนมือถือไม่ได้ ไม่ได้สร้าง APK/AAB หรืออัปโหลดรุ่นใหม่ในงานนี้

การจับภาพ Godot Editor ผ่าน computer-use ลองใหม่หนึ่งครั้งแล้วยังล้มเหลวด้วย `FrameArrived timed out` / `window capture timed out` จึงยืนยันความสามารถโหลดซีนจากการ instantiate และเรนเดอร์ แต่ไม่ได้ยืนยันภาพ Local tree ด้วย UI Editor สด Log มีคำเตือนสภาพแวดล้อมเรื่อง shader cache/user directory และ Windows certificate store; ชุดตรวจที่ระบุไม่มี SCRIPT ERROR หรือข้อทดสอบล้มเหลว Import Editor ยังมีข้อความ MultiMesh transform format ของทรัพยากรโลก ซึ่งไม่ได้แก้ในงานควบคุมนี้
