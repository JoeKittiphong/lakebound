# จำตำแหน่งแผนที่และลงเรือกลางน้ำ

กติกาเรือถูกแทนที่ด้วย [เรือเป็นอุปกรณ์ส่วนตัว](owned-boats.md): ไม่มีเรือฟรี เรือที่วางไว้ไม่คืนข้ามการเข้าแผนที่ ออกขณะอยู่บนเรือแล้วกลับมาว่ายน้ำโดยไม่มีเรือ รายละเอียดด้านล่างเกี่ยวกับการคืนตำแหน่งลำเรือและนั่งเรือเป็นพฤติกรรมก่อนการปรับนี้ ส่วนการจำจุดผู้เล่นบนฝั่ง/ในน้ำและการตรวจพิกัดยังใช้ต่อ

ปรับ 4 พฤศจิกายน 2026

## พฤติกรรม

- การเล่นปกติจำตำแหน่งผู้เล่น ทิศตัวละคร มุมกล้อง ตำแหน่งและทิศเรือ แยกตามแผนที่ทั้ง 6 พื้นที่ ครั้งแรกยังใช้จุดเริ่มต้นที่จัดไว้ในฉาก
- ออกขณะอยู่บนฝั่งจะกลับที่เดิม ออกขณะว่ายน้ำจะกลับมาว่ายน้ำที่เดิม ออกขณะอยู่บนเรือจะกลับมานั่งขับบนเรือที่ตำแหน่งเดิม โดยเรือหยุดนิ่ง
- ไม่คืนการวิ่งอัตโนมัติ ความเร็วเรือ/ผู้เล่น หรือเบ็ดและปลาที่กำลังตก ผู้ที่ออกขณะยืนตกปลาบนเรือจะกลับมาเป็นท่านั่งขับก่อน
- บันทึกเมื่อออกจากแผนที่ กด Back พักแอป หรือปิดหน้าต่าง หากกด Back แล้วเซฟไม่สำเร็จ จะคงอยู่ในแผนที่และแสดงข้อผิดพลาดเพื่อให้ลองใหม่ ใช้ atomic save เดียวกับข้อมูลปลาในบ่อ
- ตำแหน่งเป็นข้อมูลภายในเซฟผู้เล่นบนเครื่อง ไม่ได้เพิ่มการอัปโหลดพิกัดหรือขยายโปรโตคอลคลาวด์ การรีเฟรชคลาวด์จะรักษาข้อมูลตำแหน่งท้องถิ่นไว้ การแข่งขันใช้ระบบห้องและจุดเกิดของแมทช์เดิม
- เซฟเก่าจะได้รับช่อง `travel` ว่าง พิกัดที่เสียจะถูกทิ้งเฉพาะรายการนั้นโดยไม่รีเซ็ตเงินหรืออุปกรณ์ ตอนคืนสถานะจะตรวจขอบแผนที่ พื้นรองรับและ collision ก่อน ถ้าพิกัดผู้เล่นใช้ไม่ได้จะคงจุดเริ่มต้นในฉาก เรือที่ใช้ได้ยังคืนตำแหน่งแยกต่างหากได้

## ลงน้ำและขึ้นเรือ

- ปุ่ม “ลงเรือ” ยังคงเลือกจุดฝั่งใกล้ ๆ ที่เดินได้ก่อน หากไม่มี จะหาจุดน้ำข้างลำเรือในรัศมี 3.5 และ 4.5 เมตร ตรวจครบแปดทิศ รวมตัวเรือและสิ่งกีดขวาง
- จุดลงน้ำต้องอยู่ในขอบการเดิน เป็นบริเวณที่ว่ายน้ำได้ และมีที่ว่างให้ collision ผู้เล่น เมื่อออกแล้วคืน collision ผู้เล่น หยุดเรือ และเข้าสู่การว่ายน้ำ
- หากไม่มีจุดปลอดภัย ปุ่มลงเรือจะไม่พร้อมใช้งาน หากว่ายกลับมาในระยะขึ้นเรือ จะมีปุ่ม “ขึ้นเรือ” เดิม และกลับนั่งขับได้

## จุดแก้ใน Editor และโค้ด

- `actors/boat/fishing_boat.tscn`: ฉากเรือเดิมและจุดนั่ง/ยืน ค่า `water_exit_radius`, `shore_exit_radius` และ `boarding_distance` ปรับได้ใน Inspector
- `features/fishing/fishing_hud.tscn`: ปุ่ม `SafeArea/BoatActions/Exit` เดิม ใช้การตรวจจุดลงได้ทั้งฝั่งและน้ำ
- `features/gameplay/map_travel_state.gd`: รูปแบบ checkpoint, ตรวจพิกัด, คืนผู้เล่น/เรือและกล้อง
- `features/gameplay/gameplay.gd`: จังหวะเซฟและคืนตำแหน่งหลัง physics พร้อม
- `features/economy/profile_store.gd`: migration เซฟเก่าและทำความสะอาดพิกัดเสีย
- `features/economy/angler_profile.gd::store_map_state`: บันทึกตำแหน่งและประชากรปลาแบบ atomic พร้อม rollback

## การตรวจ

Godot 4.7.2 Windows ใช้โปรไฟล์ทดสอบแยกจากเซฟจริง:

```powershell
node tools/test_competition.cjs map_travel_visual boat_integration fishing_map_data hud_session cloud_sync
```

- `map_travel_visual`: 56 checks ผ่าน รวมออก/เข้าแผนที่และโหลดไฟล์ใหม่ ตำแหน่งบนฝั่ง/บนเรือ/ว่ายน้ำ ทิศเรือและกล้อง ค่าความเร็วเป็นศูนย์ ทดสอบน้ำ/ขึ้นเรือ/คืนเรือครบ 6 แผนที่ พิกัดเสีย/ใต้พื้น/นอกขอบ สิ่งกีดขวาง migration คลาวด์ rollback เซฟล้มเหลว Back และ app pause
- `boat_integration`: 54 checks ผ่าน รวมการขับเรือ ตกปลา ลงฝั่ง ลงกลางน้ำ ว่ายกลับขึ้นเรือ และเพดานเตี้ย
- `fishing_map_data`: 43 checks ผ่าน
- `hud_session`: 45 checks ผ่าน
- `cloud_sync`: 223 checks ผ่าน
- รวมชุดข้างต้น 421 checks ผ่าน ตรวจภาพ `restored-aboard.png` และ `swimming-beside-boat.png` ใน `exports/qa-competition/map_travel_visual/`
- `rainforest_cave`: การขึ้นลงเรือและขับเข้าออกถ้ำผ่าน มี failures เดิม 2 จุดเรื่องเหวี่ยง/ปลากินในถ้ำ ยืนยันโดยย้อนเฉพาะการเปลี่ยนแปลงงานนี้ชั่วคราวแล้วพบ failures เดิมทั้งสอง ผลอยู่ที่ `../output/map-travel-baseline.log` และคืนโค้ดใหม่ครบแล้ว
- ยังไม่ได้ทดสอบโทรศัพท์จริงหรือเผยแพร่ Android/Web รุ่นใหม่
