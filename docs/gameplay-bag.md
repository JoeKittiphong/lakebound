# ร้านค้าและกระเป๋าในสนาม

ซื้ออุปกรณ์ได้จากปุ่ม ร้านค้า / เตรียมอุปกรณ์ ในหน้าเมนูเท่านั้น ระหว่างอยู่ในแผนที่ทุกโหมด AnglerProfile.buy จะปฏิเสธคำสั่งซื้อโดยไม่แก้เงินหรือสต็อก

แถบล่างมีช่องคัน รอก เอ็น เหยื่อ ขอบสีแดง แตะเพื่อเลือกจากของที่มีอยู่เท่านั้น รวมสายม้วนสำรองและสายที่เก็บไว้ การเลือกใช้ยังตรวจความเข้ากันได้ตามระบบเดิม ปรับความลึกจากแถบในหน้ากระเป๋า

ช่องปลาขอบสีฟ้าแสดงครั้งละ 4 ตัว ปัดซ้ายเพื่อหน้าถัดไป ปัดขวาเพื่อย้อนกลับ ใช้ลากเมาส์หรือหมุนล้อเมาส์ได้ด้วย โหมดปกติแตะเพื่อเปิดกล่องปลารายละเอียด โหมดแข่งแสดงปลาที่จับในรอบนั้นและล้างเมื่อเริ่มรอบใหม่ คะแนนยังส่งผ่านระบบยืนยันผลเดิม ไม่บันทึกปลาสนามแข่งลงกล่องปลาปกติ

การแข่งขันใช้อุปกรณ์ที่ผู้เล่นมีและเลือกไว้ เหยื่อและสายใช้สต็อกจริงตามระบบตกปลา การจับปลาอย่างเดียวไม่เปลี่ยนข้อมูลกล่องปลาหรือคอลเลกชัน

ปรับตำแหน่ง สี ขนาดช่องได้ใน features/fishing/ui/bag_dock.tscn ซึ่งเป็นฉาก Control ที่แก้ไขใน Editor ได้โดยตรง ค่า swipe_distance อยู่ใน Inspector ของ BagDock

ทดสอบ: tests/gameplay_bag_test.gd และ tests/competition_session_test.gd

ช่องอุปกรณ์และปลาใช้โมเดล 3D จาก model_scene จริงใน bag_slot_preview.tscn แต่ละช่องมีโลกและแสงแยก อัปเดตภาพเมื่อเปลี่ยนโมเดล/ขนาดหรือเปิดกลับมาเท่านั้น ปิดการประมวลผลและแอนิเมชันโมเดลในช่อง และคืนโมเดลเมื่อซ่อนกระเป๋า ปรับมุมปลา อุปกรณ์ และระยะซูมคันจาก Inspector ของ Preview ได้

ขณะแข่งขัน HUD ซ่อนอันดับแผนที่ ปุ่มภารกิจ ตัวติดตามและข้อความภารกิจ กล่องอันดับแข่งขันอยู่ใต้แผนที่ย่อ หัวกล่องแสดงเวลาคงเหลือและกติกา รายชื่อเรียงตามอันดับจากเซิร์ฟเวอร์ รองรับ 5 คนและตัดชื่อยาวเพื่อรักษาคอลัมน์น้ำหนัก เอาปุ่มห้อง/ผลแข่งออกจากกล่อง ผลสุดท้ายยังเปิดอัตโนมัติ

ปุ่ม 1st/3rd อยู่หน้าช่องคันเบ็ด แยกจาก BagDock เพื่อให้ยังแสดงเมื่อแถบอุปกรณ์ซ่อนระหว่างตกปลา เลือกมุมกล้องได้ทุกสถานะและคงค่าที่เลือกจนผู้เล่นเปลี่ยนเอง มุมกล้องเริ่มต้นยังเป็นบุคคลที่สาม

ฉากปรับหน้าตา: features/competition/match_hud.tscn และ PerspectiveButton ใน features/fishing/fishing_hud.tscn ทดสอบตำแหน่งและพฤติกรรมด้วย tests/match_hud_layout_test.gd และ tests/detailed_equipment_camera_test.gd
