# แผนพัฒนาภารกิจ — 23 ตุลาคม 2026

## ที่มาและสถานะการตัดสินใจ

อ่านแชท “วิเคราะห์กลุ่มเป้าหมายเกม” และ “ออกแบบเนื้อหาเกมตกปลา” เทียบกับ gameplay-expansion-plan.md และโค้ดปัจจุบัน

- แชทล่าสุดอ้างถึงภารกิจ 4 ระดับ แต่รายละเอียดครบทั้ง 4 ระดับไม่ปรากฏในข้อมูลที่เครื่องมือส่งคืน ชื่อระดับและชุดภารกิจด้านล่างจึงเป็นข้อเสนอ ไม่ใช่ข้อสรุปเดิมของผู้ใช้
- ผู้ใช้ยืนยันให้ Multiplayer และการแข่งขันเป็นงานอนาคต
- ผู้ใช้ยืนยันสกินมีผลเฉพาะรูปลักษณ์และเอฟเฟกต์ การเล่นยังอาศัยทักษะ ไม่มีเลเวลเพิ่มพลัง
- ภารกิจเป็นกิจกรรมสมัครใจตามหลัก free play เดิม ไม่บังคับเพื่อเหวี่ยงเบ็ดหรือเล่นระบบหลัก
- เอกสารนี้เริ่มจากแผน และได้ลงมือพัฒนาชุดแรกแล้วตามคำสั่งผู้ใช้ ดูสถานะและหลักฐานท้ายเอกสาร

## ฐานที่มีอยู่

มี Tutorial จับปลาตัวแรก, Fish Collection, สถิติส่วนตัว, จ้าวบ่อ, ร้านค้าและโปรไฟล์เศรษฐกิจแล้ว ไม่จำเป็นต้องสร้างระบบเหล่านี้ซ้ำ

จุดเชื่อมที่ตรวจพบ: FishingController.fish_landed, FishCollection.record_catch_result และ AnglerProfile.record_catch โค้ดมีหลายจุดบันทึกผล จึงต้องตามเส้นทางให้ชัดและสร้างเหตุการณ์จับสำเร็จเพียงครั้งเดียวก่อนต่อภารกิจ

## เป้าหมายรุ่นแรก

ทำให้บ่อเดิมมีเป้าหมายทั้งสั้นและยาว โดยให้ผู้เล่นฝึกเลือกเหยื่อ ความลึก และต่อสู้กับปลา เริ่มด้วยชุดภารกิจถาวร 12 ข้อ ไม่หมดอายุ ทำซ้ำรับรางวัลไม่ได้ และไม่มีข้อจำกัดเวลาที่กดดันผู้เล่น

| ระดับที่เสนอ | จำนวน | ตัวอย่าง | จุดประสงค์ |
|---|---:|---|---|
| Easy | 3 | จับปลาใดก็ได้ 3 ตัว; จับปลานิล 2 ตัว; จับปลารวม 2 ชนิด | เรียนรู้วงจรการเล่น |
| Normal | 3 | จับน้ำหนักรวมตามเป้า; จับด้วยเหยื่อธรรมชาติ 2 แบบ; จับปลาด้วยเหยื่อปลอม | เรียนรู้การเลือกวิธีตก |
| Hard | 3 | จับปลาเป้าหมายเกินน้ำหนักกำหนด; จับปลานักล่าด้วยเหยื่อที่กำหนด; จับปลาจากช่วงความลึกที่กำหนด | ใช้ความรู้และการควบคุม |
| Pro | 3 | พิชิตจ้าวบ่อ 1 ครั้ง; จับปลาใหญ่ตามเกณฑ์ชนิด; จับปลาหลายชนิดตามชุดเป้าหมาย | เป้าหมายระยะยาว |

ตัวเลขน้ำหนัก จำนวน และชนิดปลาของแต่ละข้อยังเป็นค่าร่าง ต้องตรวจข้อมูลประชากรปลา เหยื่อ และอุปกรณ์จริงก่อนกำหนด หลีกเลี่ยงโจทย์ที่ต้องรอปลาหายากเกินไปหรือปลาไม่มีในบ่อ

ภารกิจทำลาย Personal Best เหมาะกับการขยายภายหลัง เพราะสถิติที่สูงมากอาจทำให้โจทย์แทบเป็นไปไม่ได้ รุ่นแรกใช้เกณฑ์น้ำหนักที่ตรวจสอบได้แทน

## กติกาที่เสนอ

- เริ่มนับภารกิจทั่วไปหลังจบหรือข้าม Tutorial ไม่ย้อนหลังจากยอดรวมที่แยกบริบทไม่ได้; ภารกิจค้นพบถาวรอาจอ่าน Collection เดิมได้เมื่อกำหนดไว้อย่างชัดเจน
- จับสำเร็จนับได้ทั้งเก็บและปล่อย ไม่บังคับขายหรือใส่กล่อง; ต้องป้องกันการนับปลาตัวเดิมซ้ำจากเหตุการณ์ซ้ำ
- ปลาหนึ่งตัวเพิ่มความคืบหน้าได้หลายภารกิจที่ตรงเงื่อนไข
- แยก “ทำสำเร็จ” กับ “รับรางวัลแล้ว”; รางวัลและสถานะรับต้องบันทึกในธุรกรรมเดียวกัน หากบันทึกล้มเหลวต้องไม่จ่ายบางส่วน
- เริ่มด้วย Coins หรือของใช้ที่รองรับอยู่แล้ว จำนวนรางวัลต้องเทียบต้นทุนเหยื่อ สาย และรายได้ขายปลา
- ตั๋วกาชา สกิน และฉายาเป็นข้อเสนอระยะต่อไป ยังไม่แจกสิทธิ์ที่ระบบใช้จริงไม่ได้
- ภารกิจอาจระบุชนิดปลาเป็นเป้าหมาย แต่ไม่เปิดเผยข้อมูลเหยื่อหรือแหล่งอาศัยใน Collection ก่อนค้นพบ; ชื่อจ้าวบ่อยังเป็น ??? ตามกติกาเดิม
- ไม่มีรีเซ็ตรายวันในรุ่นแรก จึงไม่ต้องเพิ่มภาระเรื่องเปลี่ยนนาฬิกาหรือวันหมดอายุ

## ลำดับการทำงานและเกณฑ์ผ่าน

1. **ตรวจเส้นทางจับปลาและล็อกเนื้อหา** — ระบุจุดยืนยันผลจับและพฤติกรรมปล่อยปลา ตรวจชนิดปลา/น้ำหนัก/เหยื่อที่เข้าถึงได้จริง แล้วกำหนด 12 ภารกิจพร้อมรางวัล ทุกข้อมีวิธีทำสำเร็จในบ่อเดิม
2. **ทำแกนภารกิจและการบันทึก** — แยกข้อมูลภารกิจเป็น Godot Resource พร้อม stable ID และ revision; evaluator รองรับชนิดปลา จำนวน น้ำหนัก เหยื่อ ความลึก ชนิดไม่ซ้ำ และจ้าวบ่อ มี event ID กันนับซ้ำ และ reward claim ID กันรับซ้ำ
3. **ต่อเข้าระบบจับจริงและเศรษฐกิจ** — ส่งข้อมูลที่ยืนยันแล้ว เช่น catch ID, fish instance ID, map, species, weight, bait, depth, boss ณ เวลาจับ; ตรวจวิธีบันทึกโปรไฟล์ก่อนเลือกขอบเขตธุรกรรม ไม่ผูกกับการเปิดหน้าผลจับซ้ำ
4. **ทำหน้า UI ที่แก้ใน Editor ได้** — ปุ่มภารกิจ, รายการ 4 ระดับ, เงื่อนไข/ความคืบหน้า/รางวัล/รับรางวัล, ติดตามได้หนึ่งข้อบน HUD และแจ้งสำเร็จสั้น ๆ จัดวางหลัง Tutorial ไม่บังจอยตกปลา
5. **ทดสอบและปรับเนื้อหา** — ตรวจเก็บ/ปล่อย, หนึ่งตัวตรงหลายข้อ, event ซ้ำ, กดรับซ้ำ, ออกจากเกมแล้วกลับมา, เซฟล้มเหลว, เซฟเก่า, ข้อมูลภารกิจเปลี่ยน revision และปลาเป้าหมายไม่มีในแผนที่ ตรวจมือถือทั้งอัตราส่วน 16:9 และจอกว้าง

ผ่าน milestone เมื่อเล่นครบตั้งแต่ Tutorial → ทำภารกิจ → รับรางวัล → ปิดเปิดเกม โดยสถานะและเงินถูกต้อง ไม่มีภารกิจขวางการตกปลาอิสระ และไม่มีรางวัลซ้ำ

## การประเมินหลังทดลองเล่น

จดเวลาที่ใช้ทำข้อแรกและจบแต่ละระดับ จุดที่ผู้เล่นไม่เข้าใจ อัตรายกเลิกหรือหยุดทำ และต้นทุนสุทธิเทียบรางวัล ใช้บันทึกทดสอบในเครื่องก่อน ไม่เพิ่มบริการ analytics โดยอัตโนมัติ ปรับจำนวนและน้ำหนักจากผลเล่นจริงก่อนขยายเนื้อหา

## ลำดับถัดไป

เมื่อชุดถาวรเล่นสนุกแล้ว จึงเพิ่มชุดโจทย์หมุนเวียนหรือรายวันโดยออกแบบการรีเซ็ตและการเล่นออฟไลน์ก่อน ตามด้วยความสำเร็จและรางวัลตกแต่ง ส่วนกาชา การขายแผนที่ Online Leaderboard และ Multiplayer จัดเป็น milestone แยกตามบริการที่ต้องใช้ ไม่รวมในงานภารกิจรุ่นแรก

## สถานะชุดแรก

- เพิ่มภารกิจถาวรครบ 12 ข้อจากตารางด้านบน แก้เงื่อนไขและรางวัลใน `data/missions/*.tres`
- เพิ่มหน้า `features/missions/mission_panel.tscn` และการ์ด `mission_row.tscn` พร้อมปุ่มเปิด ติดตามหนึ่งข้อ รับรางวัล และข้อความสำเร็จ
- เริ่มหลังบทสอนจบหรือข้าม มีปุ่มข้ามบทสอนโดยสมัครใจ ไม่ดึงประวัติเก่ามานับย้อนหลัง
- จับสำเร็จนับทั้งเก็บและปล่อย ใช้ความลึกตอนกัดและสถานะจ้าวบ่อตอนจับได้
- รหัสปลาอยู่ใน snapshot ป้องกันนับปลาที่ปล่อยแล้วจับซ้ำ แม้โหลดบ่อใหม่ ส่วน catch ID กันส่งเหตุการณ์เดิมซ้ำ
- เซฟความคืบหน้าในโปรไฟล์เดิม รับรางวัลและสถานะรับเป็นธุรกรรมเดียว เซฟ v1 เดิมเพิ่มข้อมูลภารกิจโดยรักษาเงินและประวัติ
- รางวัลรวมชุดแรก 695 เหรียญ เป็นค่าทดลอง ไม่มีรางวัลเพิ่มพลัง
