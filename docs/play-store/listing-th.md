## Full description
Lakebound เป็นเกมตกปลาสามมิติที่กำลังพัฒนา เลือกมุมมองริมทะเลสาบ เลือกเหยื่อและความลึก แล้วเหวี่ยงเบ็ดเพื่อทดสอบฝีมือกับปลาในบ่อ

สิ่งที่เล่นได้ในรุ่นทดสอบ
• หมุนกล้องและควบคุมคันเบ็ดด้วยระบบสัมผัส
• เลือกเหยื่อและระดับความลึก
• จับจังหวะปลากินเหยื่อและควบคุมความตึงของสาย
• เลือกเก็บหรือปล่อยปลาที่ตกได้
• ดูสมุดสะสมปลา จำนวนที่ตกได้ และสถิติน้ำหนัก

สถิติในสมุดสะสมปลาบันทึกไว้ในอุปกรณ์และเปิดดูได้ในการเล่นครั้งถัดไป ยังไม่มีระบบสำรองข้อมูลบนคลาวด์ เกมยังอยู่ระหว่างการพัฒนา

รุ่นนี้เล่นแบบออฟไลน์ ไม่มีบัญชีผู้ใช้ โฆษณา หรือการซื้อภายในแอป
