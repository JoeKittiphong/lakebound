# Collection แยกตามแผนที่

เพิ่มแท็บทั้งหมดและหกแผนที่ แต่ละแท็บแสดงจำนวนชนิดที่จับได้/ชนิดทั้งหมด พร้อมสรุปจำนวนที่ยังขาด และสวิตช์ **เฉพาะที่ยังไม่พบ** ปลาที่ยังไม่พบยังเป็นเงาและเครื่องหมายคำถามตามแบบเดิม เมื่อกรองแล้วไม่มีชนิดที่ขาดจะแสดงข้อความจับครบแล้ว

รายชื่อปลาอิง `PondEcosystem.species` ของซีนแผนที่จริง: แม่น้ำ 28, บึงบัว 14, ลำธาร 28, เขื่อน 14, ป่าชายเลน 14, ทะเล 15 ชนิด ปลาเดียวกันอาจมีในหลายแผนที่ จึงนับความคืบหน้าแยกกัน ส่วนแท็บทั้งหมดนับชนิดไม่ซ้ำตามสมุดสะสมเดิม

การค้นพบรายแผนที่อ่านจาก `profile.data.history.map_bests` ซึ่งคงข้อมูลตลอดอายุเซฟ รวมกับ journal เดิมสำหรับข้อมูลเก่าที่ยังไม่ย้ายเข้าประวัติสรุป จึงไม่ลืมชนิดที่ค้นพบเมื่อ journal เหลือเฉพาะสิบสถิติที่ดีที่สุด ไม่แก้หรือเพิ่มรูปแบบเซฟ และไม่เดาแผนที่ให้สถิติรวมเก่าที่ไม่มีข้อมูลแผนที่

การ์ดรายแผนที่แสดงน้ำหนักสูงสุดในแผนที่นั้น ไม่ใช้จำนวนตัวจากสถิติทั่วเกมมาปะปน หากแตะประวัติจากแท็บแผนที่ จะเปิดแผนที่ที่เลือกไว้โดยตรง การสลับแท็บไม่ส่งสัญญาณเปิด modal ซ้ำ และจำแท็บ/ตัวกรองเมื่อปิดแล้วเปิดใหม่

แก้ UI ได้ที่ `features/collection/collection_panel.tscn`: MapTabs, Filters, Header/Summary รายชื่อปลาแบบข้อมูลล้วนอยู่ที่ `data/regions/collection_species.gd` สร้างใหม่จากซีนด้วย `../exports/build_collection_regions.py` มีเทสต์เทียบกับซีนจริงทั้งหกเพื่อจับข้อมูลคลาดเคลื่อนเมื่อเปลี่ยนประชากรปลา

หลักฐานอยู่ที่ `../exports/qa-collection-tabs/`:

- `collection_tabs_test.gd`: 69 ข้อผ่าน รวมการแตะแท็บจริง แยกการค้นพบข้ามแผนที่ ประวัติหลัง compact ตัวกรอง/สถานะครบ และ layout ที่ 1280×720, 2400×1080, 1024×768
- `hud_session_test.gd`: 45 ข้อผ่าน
- `fishing_map_data_test.gd`: 43 ข้อผ่าน ปรับตำแหน่งเซฟของเทสต์ให้รับ LAKEBOUND_QA_DIR เพื่อไม่เขียน user directory นอก sandbox
- `collection_test.gd`: ผ่าน ไม่มีข้อทดสอบล้มเหลว รวม modal รูปปลา สถิติ และการเลื่อนรายการจนสุด แยก fixture ทดสอบสมุดโดยตรงจากระบบ economy และไฟล์บทสอนผู้เล่น

ตรวจพบและแก้การส่ง tab_changed ระหว่างสร้างแท็บครั้งแรก ซึ่งอาจเรียก refresh ก่อนจำนวนแท็บครบ โดยบล็อกสัญญาณเฉพาะช่วงสร้างรายการ แล้วเปิดการรับอินพุตตามปกติ

ภาพ `collection_*_map*.png` เป็นภาพเรนเดอร์จริงของ UI โดยใช้ข้อมูลทดสอบหนึ่งชนิดที่จับในบึงบัว เพื่อให้เห็นความต่างระหว่างสถิติรวมกับแต่ละแผนที่ เป็นการตรวจขนาดจอมือถือบนเดสก์ท็อป ยังไม่ได้ทดสอบบนโทรศัพท์จริง
