# Refactor 28 October 2026

## Scope and baseline

The playable Godot project is this directory, not the parent art workspace.
Keep authored scenes, resource UIDs and existing player saves. Preserve gameplay
tuning except for verified defects found by regression checks.
The working tree already contains substantial changes; this work builds on them.

The owner confirmed that Google Sheets is the only online persistence service.
Remove the retired PostgreSQL/SQLite implementation instead of maintaining it.
Local profile/collection saves and the pending catch recovery queue remain needed
for offline play and failed uploads.

Baseline: Godot 4.7.2. Import, catch_archive, catch_settlement, social_profile,
sheets_ranking_sync, server_settings, hud_performance and optimization passed.
Repository candidate audit: 1,803 files, no findings within its documented scope.
The test inventory reported five unregistered suites, including obsolete server tests.
Evidence: `exports/qa-refactor-2026-10-28/baseline/` (local artifacts).

## Findings and structure

| Area | Finding and decision |
|---|---|
| Project boundary | Parent folders contain source art, Blender tooling and exports. The Git/game root is `fishing-game/`; moving those art folders would add risk without improving runtime. |
| Runtime layout | `features/`, `actors/`, `world/`, `data/` and `shared/` already separate scene ownership and resources. Keep this layout and scene UIDs. |
| Persistence | ProfileStore, CollectionStore, AtomicConfig and CatchSettlement already cover offline saves and recovery. Their regression suites pass; retain these boundaries. |
| Online service | Obsolete Python/SQL source and a second client protocol remained beside the active Sheets integration. Remove them and group the remaining service source under `services/`. |
| Presentation performance | Profile changes rebuilt ranking rows while the panel was hidden. Restrict row construction to visible UI. |
| External data | Network and disk cache decoded the same schema separately. Extract RankingSnapshot and apply identical bounds/type/catalog checks. |
| Verification | Five source tests were missing from the runner; some also depended on the retired API or lacked result markers. Register retained tests, update fixtures and remove obsolete coverage. |

## Implementation plan and acceptance

- [x] Move Apps Script and its tools to `services/google_sheets/`; exclude services
  and retired local service data from Godot and Git publication as appropriate.
  Remove Python APIs, SQL, launch/backup tools and their tests. Update current docs.
  Preserve ignored local database files; removing old source does not delete data
  or alter machine services.
- [x] Make the client Sheets-only: exact Web App endpoint allowlist, migrate valid
  saved Sheets URLs, reject obsolete/custom HTTP APIs, remove their request and
  pagination branches. Retain the restricted Google content redirect as a GET
  without credentials. Bound response bytes before parsing.
- [x] Extract compact ranking validation into one pure class shared by HTTP and
  disk cache. Reject malformed rows/metadata without acknowledging failed uploads
  or replacing a good cache. Strengthen Apps Script request type checks.
- [x] Avoid rebuilding a hidden ranking panel on profile changes; measure hidden
  updates and verify reopening shows current data. Preserve cached Top100 rendering.
- [x] Repair the test inventory, isolate offline regression from opt-in live HTTP,
  run focused tests then broader gameplay regression, inspect rendered ranking UI,
  and record results/limitations here and in the architecture documentation.

No release build or deployment is part of this refactor. The deployed Apps Script
version is independent of the local source; report any changes requiring deployment.

Two additional regressions were resolved during broader verification:

1. The authored camera offset was 3.8 m, leaving only about 1.81 m clearance at
   +15° pitch, below the existing >2 m test and documented ~2.1 m clearance.
   Restore its saved height to 4.1 m. The original assertion, terrain checks,
   camera movement and mobile camera visual checks pass without weakening limits.
2. `active_scene_movement` used a fixed camera-drag point `(900, 200)` that now
   overlaps the new-player tutorial's Skip button. Move the gesture into the empty
   viewport and assert that it avoids the tutorial control. The full touch/mouse
   dispatch and independent rod/camera ownership checks now pass.
