# เพื่อน สถานะออนไลน์ และคำเชิญเข้าห้อง

เพิ่มวันที่ 4 พฤศจิกายน 2026 ใน backend Cloudflare เดิมและเกมที่รันจากโปรเจกต์นี้ ยังไม่เผยแพร่ Android/PWA รุ่นใหม่

## วิธีใช้

1. ล็อกอิน Google แล้วเลือก **แข่งขันกับเพื่อน → เพื่อน / คำเชิญ**
2. คัดลอกรหัสเพื่อนของตัวเอง (8 ตัว) ส่งให้อีกคน หรือใส่รหัสของอีกคนเพื่อส่งคำขอ
3. ผู้รับต้องกดยอมรับก่อน ทั้งสองฝ่ายจึงเห็นกันในรายชื่อและเห็นสถานะ **ออนไลน์ / อยู่ในห้อง / กำลังแข่งขัน / ออฟไลน์**
4. สร้างหรือเข้าห้องที่ยังรอผู้เล่น แล้วกด **ชวนเข้าห้อง** ข้างเพื่อนที่ออนไลน์และยังไม่อยู่ในห้องอื่น
5. ผู้รับเปิดคำเชิญและกด **เข้าห้อง** ไม่เข้าห้องให้อัตโนมัติ หากมีห้องอยู่แล้วต้องออกก่อน คำเชิญมีอายุ 60 วินาที

หาห้องด่วนเป็นห้องเปิด ไม่ต้องเป็นเพื่อนกันก่อน เมื่อเข้าห้องแล้ว แถวของผู้เล่นอื่นมีปุ่ม **เพิ่มเพื่อน** โดยไม่ต้องคัดลอกรหัส ปุ่มเปลี่ยนเป็น **ส่งคำขอแล้ว**, **รับเป็นเพื่อน** หรือ **เป็นเพื่อนแล้ว** ตามสถานะ และไม่แสดงปุ่มเพิ่มตัวเอง

ปุ่มแข่งขันในเมนูและปุ่มเพื่อนแสดงจำนวนคำขอ/คำเชิญ รายชื่อมีปฏิเสธคำขอ ยกเลิกคำขอที่ส่ง และลบเพื่อนพร้อมกล่องยืนยัน

## ข้อมูลและพฤติกรรม

- เก็บโปรไฟล์รหัสเพื่อนและความสัมพันธ์แบบ durable แยกจากข้อมูลห้องใน SQLite Durable Object เดิม การคืนห้องเมื่อคนออกหมดไม่ลบรายชื่อเพื่อน
- ไม่ใช้ชื่อซ้ำหรืออีเมลค้นหาผู้เล่น ใช้รหัสเพื่อน 8 ตัวที่ตรวจการชนของรหัสและคงเดิมเมื่อ reconnect ชื่อแสดงมาจาก identity ที่ Supabase ยืนยัน ไม่เชื่อ player ID/name ที่ผู้ส่งแนบมา
- เปิด socket สำหรับเพื่อนขณะล็อกอินและเปิดเกม รวมถึงอยู่เมนู/เล่นคนเดียว สถานะออนไลน์จึงหมายถึงมี authenticated connection ไม่ใช่เพียงเคยเข้าเกม วันล่าสุดไม่มีการเก็บ/แสดง
- เฉพาะเพื่อนที่ยอมรับกันแล้วจึงได้รับ presence อัปเดต ผู้ส่งคำขอที่ยังไม่ถูกตอบรับไม่เห็นสถานะเพื่อน รายชื่อไม่ถูก broadcast สาธารณะ
- ใช้ push แทน poll ถี่ และไม่เขียนฐานข้อมูลทุก heartbeat เมื่อออกจากห้องยังอยู่ในรายชื่อออนไลน์ได้ ขณะที่กด logout/ปิดเกมจะปิด transport และสถานะอัปเดตเมื่อ server ตรวจพบการปิด connection
- 100 connections ที่ยืนยันตัวตนพร้อมกันของระบบปัจจุบัน **รวมผู้เล่นที่เปิดเมนูออนไลน์เพื่อใช้เพื่อนด้วย** ไม่ได้แยกโควตาเพื่อนเพิ่มต่างหากจากห้อง
- จำกัดเพื่อน 100 คน, คำขอขาเข้า 30, ขาออก 20 และส่งคำขอใหม่ 30 ครั้ง/วันต่อบัญชี จำกัดคำเชิญที่ยังไม่หมดอายุ 10 รายการต่อผู้รับ
- server ตรวจผู้ส่งเป็นเพื่อน/อยู่ห้อง lobby, ผู้รับออนไลน์/ว่าง, ที่นั่ง และ round ID อีกครั้งตอนตอบรับ ปฏิเสธคำเชิญหมดอายุ ห้องปิด ห้องเริ่มแล้ว ห้องเต็ม หรือคำเชิญของคนอื่น ลบเพื่อนจะยกเลิกคำเชิญจากคู่นั้นด้วย
- ไม่เพิ่มแพ็กเกจหรือคีย์บริการใหม่ ใช้ identity RPC และ Worker Secrets ที่อนุญาตเดิม ค่า storage requests/writes สำหรับรายชื่อยังนับในโควตา Cloudflare เดิม

## แก้ไขและตรวจสอบ

- ฝั่ง server: `services/cloudflare-match/src/social.mjs` และ handler ใน `worker.mjs`
- ฝั่งเกม: `match_friends.gd` ใต้ `Competition/Friends`, transport เดิมใน `match_edge.gd`
- หน้าจอแก้ใน Editor ได้ที่ `features/competition/friends_panel.tscn` และแถวเพื่อนที่ `friend_row.tscn` เปิดจาก child `FriendsPanel` ของ `match_panel.tscn`

ผลทดสอบ: backend 9 ชุดผ่าน รวม request/accept/remove, private presence, invites, disconnect/reconnect, hibernation, expiry, ห้องปิด และ regression 100 sockets/20 ห้อง สองเกม Godot ใช้บัญชีจำลองใน local workerd เพิ่มเพื่อน ตอบรับ และชวนเข้าห้องเดียวกันสำเร็จทั้งคู่ UI render 1280×720 ผ่าน 6 checks และ client regression 106 checks ผ่าน ไม่มีการส่งคำขอ/คำเชิญทดสอบไปยังผู้ใช้จริง

ภาพ QA `exports/qa-two-player/friends-panel.png` เป็นข้อมูลตัวอย่าง ไม่ใช่รายชื่อผู้เล่นจริง โปรไฟล์/คำเชิญใช้ fake identity เฉพาะ runtime ในเครื่องและไม่ได้ deploy ตัวจำลอง auth ขึ้น production

## เพิ่มเพื่อนจากรายชื่อห้อง

อัปเดต 4 พฤศจิกายน 2026: `request_member` ตรวจใน server ว่าผู้ส่งกับผู้รับเป็นสมาชิกที่ยังไม่ออกจากห้องเดียวกันจริง ก่อนใช้กระบวนการคำขอ/ขีดจำกัดเดิม จึงไม่เปิดให้ระบุ player ID ของคนต่างห้องเพื่อส่งคำขอผ่านเส้นทางนี้ การเพิ่มจากรหัสเพื่อนยังใช้ได้ตามเดิม

ทดสอบสองเกมผ่านปุ่ม UI จริง: เริ่มจากไม่มีความสัมพันธ์เพื่อน กดหาห้องด่วนเข้าห้องเดียวกัน จากนั้นกดเพิ่มเพื่อนและรับคำขอที่แถวผู้เล่นจนทั้งสองฝั่งแสดงเป็นเพื่อนแล้ว ผ่านทั้งคู่ Backend ทั้ง 9 ชุดผ่านและตรวจไม่ให้ส่งคำขอให้คนต่างห้อง ภาพ `exports/qa-two-player/member-friends-panel.png` แสดงสี่สถานะและแถวตัวเอง รวม 5 คน โดย UI checks 6 ข้อผ่าน

แก้รูปแบบแถวใน Editor ที่ `match_row.tscn` ซึ่งมี child `Line/AddFriend` ปรับระยะ padding ให้ปุ่มทั้งห้าแถวมองเห็นในหน้าจอ 1280×720 ต้องเปิดเกมใหม่เพื่อโหลด UI รุ่นที่เพิ่มปุ่ม
