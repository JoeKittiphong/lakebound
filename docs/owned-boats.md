# เรือเป็นอุปกรณ์ส่วนตัว

ปรับ 4 พฤศจิกายน 2026 แทนกติกาเดิมที่มีเรือฟรีและคืนเรือที่วางไว้ข้ามการเข้าแผนที่

## การใช้งาน

1. ร้านหน้าเมนูมีหมวด “เรือ” เริ่มด้วยเรือตกปลาเลคสกิฟฟ์ ราคา 1,500 เหรียญ ซื้อครั้งเดียว ใช้ซ้ำได้ ไม่อยู่ในชุดอุปกรณ์ทดลองฟรี
2. ซื้อแล้วกดเลือกใช้ เพิ่มช่อง “เรือ” เป็นช่องที่ห้าในอุปกรณ์ข้างช่องเหยื่อ ถ้ามีเรือแต่ยังไม่ได้เลือก ช่องนี้เปิดกระเป๋าหมวดเรือให้เลือก ถ้าไม่มีเรือจะแจ้งให้ซื้อจากร้านหน้าเมนู
3. ต้องยืนบนฝั่ง/ท่าเรือ ไม่ว่ายน้ำ ไม่ยืนลุยน้ำ และไม่อยู่บนเรือ จึงกดใช้ได้ เข้าหน้าตัวอย่างวางเรือที่หยุดการเดิน แต่แพนกล้องได้
4. ใช้เครื่องหมายกลางจอเลือกตำแหน่งน้ำ ตัวเรือโปร่งใสแสดงตำแหน่งจริง กดยืนยันวางหรือยกเลิกได้ จุดวางต้องห่าง 3–22 เมตร ตรวจน้ำลึกทั้งลำ ขอบพื้นที่ การชน และแนวมองถึงจุดวาง การยืนยันตรวจสิทธิ์เจ้าของและการเลือกเรือซ้ำอีกครั้ง
5. เข้าประชิดเรือเพื่อขึ้นขับ ปุ่ม “ตกปลา / เดิน” เลิกขับและหยุดลำเรือ จากนั้นใช้จอยเดินหาตำแหน่งบนดาดฟ้าได้ รวมถึงขณะตกปลา ขอบดาดฟ้าป้องกันเดินตกเรือ มีพื้นที่หลบ console และตรวจสิ่งกีดขวางเหนือผู้เล่น
6. ปุ่มขับ/ตกปลา ลงเรือ และเก็บเรืออยู่ในคอลัมน์ตัวเลขระยะเหวี่ยงเหนือจอยคันเบ็ด ปุ่มเก็บอยู่ใต้ปุ่มลงเรือ กระโดดซ่อนชั่วคราวเมื่อมีเมนูเรือตรงบริเวณนั้น จึงไม่ทับกัน
7. เก็บเรือไม่ได้ระหว่างขับ เมื่อยืนบนเรือจะลงฝั่งหรือลงน้ำที่ปลอดภัยก่อนเก็บ เมื่ออยู่นอกเรือต้องเข้าใกล้เรือจึงเก็บได้ การเก็บไม่หักจำนวนเรือหรือเงิน และยังเรียกใหม่จากฝั่งได้
8. เรือที่วางไว้เป็นวัตถุของการเล่นครั้งนั้นเท่านั้น ออกแผนที่แล้วไม่คืนลำเรือ หากออกขณะอยู่บนเรือ จะกลับมาลอยน้ำโดยไม่มีเรือ ต้องกลับฝั่งก่อนเรียกใช้ใหม่ หากบริเวณน้ำตื้นจนว่ายไม่ได้ ใช้จุดลงฝั่งปลอดภัยแทน การเป็นเจ้าของและการเลือกเรือยังอยู่ในเซฟ

## โครงสร้างและการเพิ่มรุ่นใหม่

- `data/equipment/boats/lake_skiff.tres`: TackleItem ของเรือ ราคา ชื่อ ข้อความ และโมเดล preview
- `data/equipment/boats/lake_skiff_spec.tres`: สเปกแยกจากสินค้า ปรับความเร็ว อัตราเร่ง ความไวเลี้ยว น้ำลึกขั้นต่ำ ขอบดาดฟ้า ความเร็วเดิน และระยะวางใน Inspector
- `features/gameplay/boat_loadout.gd`: จัดการสถานะยังไม่วาง/ตัวอย่างวาง/วางแล้ว/เก็บกลับ แยกจากการซื้อและระบบขับเรือ
- `actors/boat/fishing_boat.tscn`: ลำเรือจริง, collision, จุดนั่งและจุดเริ่มยืน `deck_obstacles` ปรับพื้นที่ console ที่เดินผ่านไม่ได้
- `features/fishing/ui/bag_dock.tscn`: ช่อง Boat เป็น Button และ preview จริงในฉาก
- `features/fishing/fishing_hud.tscn`: `BoatPlacement` เป็นหน้าเล็งพร้อมปุ่มยืนยัน/ยกเลิก; `SafeArea/BoatActions/Pack` เป็นปุ่มเก็บเรือที่จัดด้วย VBoxContainer
- `features/gameplay/map_travel_state.gd`: ไม่บันทึกลำเรือ และไม่คืนลำเรือจาก checkpoint รูปแบบเก่าด้วย

เพิ่มรุ่นใหม่โดยสร้างสินค้า `.tres` และสเปก `.tres` พร้อม ID ใหม่ ใส่ใน TackleCatalog สเปกเลือกฉากเรือผ่าน `scene_path` เพื่อไม่ให้โหลดตัวละคร/เกมวนกลับเข้ามาระหว่างโหลดแคตตาล็อก ภายในฉากต้องมี root FishingBoat และชื่อ `CollisionShape3D`, `DriverAnchor`, `FishingAnchor`, `DriverClearance`, `StandingClearance` ตามสัญญาของระบบเดิม ขนาดพื้นที่วางอ่านจาก collision ของลำเรือ จึงรองรับรุ่นใหญ่กว่าเดิม

โมเดล preview ใช้ `.model_scene` ที่ไม่มีพฤติกรรมเกม สเปกใช้ฉากจริงที่มีตัวควบคุม เพิ่มฉากใหม่พร้อม dependencies เข้า selected export resources เมื่อทำแพ็กเกม รุ่นปัจจุบันฉาก FishingBoat อยู่ใน dependencies ของทุกแผนที่อยู่แล้ว

ใช้ `tools/build_cloud_catalog.gd` เพื่อ append wire ID ใหม่ ห้ามสลับหรือใช้รหัสเก่าซ้ำ แล้วทำ migration เพิ่ม server catalog ของรุ่นนั้น รุ่นแรกใช้ wire ID 81 ไม่แก้ระบบควบคุมหรือช่อง UI เมื่อต้องการเพิ่มรุ่น

## เซฟและคลาวด์

- เซฟเก่ารับช่อง `equipped.boat` ว่าง ไม่แจกเรือ ไม่หักเงิน ไม่รีเซ็ตปลา/อุปกรณ์
- ซื้อ/เลือกใช้ใช้ transaction เดิม มี rollback เมื่อเขียนเซฟไม่สำเร็จ อุปกรณ์เรือไม่ถูกใช้หมดเมื่อวางหรือเก็บ
- ทดสอบ migration `services/supabase/migrations/202611040018_owned_boats.sql` แล้ว: append สินค้าตาม ID คงที่ และเพิ่ม boat ใน guard ของ loadout ไม่มีการแจกเหรียญ รีเซ็ตข้อมูล หรือเปิดสิทธิ์ตารางเพิ่ม
- **migration ยังไม่ได้ใช้กับ production** การตรวจ browser ถูก automatic approval review ปฏิเสธเพราะหน้าต่างที่มีอยู่เป็น OAuth callback ที่มีข้อมูลยืนยันตัวตน จึงไม่แตะหน้าต่างนั้น การตั้งค่า `[cloud] enabled=false` เดิมยังคงอยู่ ระบบในโปรเจกต์ใช้งานผ่านเซฟเครื่องได้ ต้องลง migration ก่อนเปิด cloud save ของรุ่นใหม่นี้

## การตรวจ

Godot 4.7.2 Windows กับโปรไฟล์ทดสอบแยกจากเซฟจริง:

```powershell
node tools/test_competition.cjs owned_boats_visual boat_shop_visual map_travel_visual boat_integration cloud_sync gameplay_bag hud_session fishing_map_data match_hud_layout perspective_cast_visual
node services/supabase/test_cloud.cjs
```

- เรือแบบอุปกรณ์ 51 checks ผ่าน: ซื้อ/เลือกใช้/เป็นเจ้าของ, UI เลือกจุดวางและแพนกล้อง, ยกเลิก, เปิดเมนูระหว่างวาง, ยืนยันซ้ำตรวจสิทธิ์, ลงน้ำ, เดินบนเรือ, ขอบดาดฟ้า, เก็บขณะขับไม่ได้, ใช้ซ้ำ, ออกแล้วกลับมาไม่มีเรือ
- ร้านเรือ 10 checks ผ่าน รวมซื้อและเลือกผ่านทัชจริง โมเดลสามมิติและชื่อในจอ 960×540, 1280×720, 2400×1080
- map travel 56, boat integration 54, cloud sync 223, HUD session 45, map data 43, match HUD 36, perspective cast 25 checks ผ่าน; gameplay bag ผ่าน รวมชุดหลัก Godot 543 checks และ PostgreSQL 31 checks รวม 574 checks
- PostgreSQL ใช้คลัสเตอร์ชั่วคราวบน loopback ไม่แตะ production ตรวจราคา server, retry ไม่ซื้อซ้ำ, ห้ามซื้อสินค้าถาวรซ้ำ, equip/unequip, not-owned, migration รันซ้ำได้ และรักษารหัสสินค้าเดิม
- ตรวจภาพ `boat-placement.png`, `boat-actions-*.png`, `returned-without-boat.png` ใน `exports/qa-competition/owned_boats_visual/` และภาพร้านใน `exports/qa-competition/boat_shop_visual/`
- equipment_catalog ยังมี failures เดิม 10 จุด (การเลือกเอ็นและพฤติกรรมเหยื่อ) ทดสอบควบคุมโดยเอารายการเรือออกและปิดการ setup เรือแล้ว ยังพบ failures เดิมทั้ง 10 จุด ผลใน `../output/owned-boat-catalog-baseline.log` คืนโค้ดเรือแล้ว
- การจับภาพหน้าต่าง Editor ไม่สำเร็จเนื่องจาก capture timeout จึงตรวจโครงสร้างจากฉากที่บันทึกและตรวจภาพเกมแบบ rendered ไม่อ้างว่าตรวจด้วยหน้าต่าง Editor สำเร็จ
- ยังไม่ได้ทดสอบมือถือจริงหรือเผยแพร่ Android/Web รุ่นใหม่
