# แผนเปลี่ยน UI เป็น generated atlas — 23 ตุลาคม 2026

## เป้าหมาย

ใช้กราฟิกที่เจนเป็นภาพเดียวสำหรับผิวปุ่ม พาเนล ช่องรายการ แถบความคืบหน้า และไอคอน UI แนว modern flat เรียบ ไม่มีลายวัสดุหรือกรอบประดับ ใช้กรมท่า/สี slate กับ mint เพื่ออ่านชัดเหนือฉากน้ำ ใช้ข้อความจริงและฟอนต์ไทยเดิม

## การจัดทรัพยากร

- PNG atlas เดียว โปร่งใส ไม่เปิด mipmaps สำหรับ UI (ผลจริง: ต้นฉบับเจน 1254×1254 และนำเข้า Godot ที่ 512×512 เพื่อคุมงบหน่วยความจำ)
- AtlasTexture หลาย .tres เป็นเพียงข้อมูล region อ้าง PNG เดียว ไม่สร้างภาพแยก
- StyleBoxTexture แบบ nine-slice เก็บมุมโค้งไว้เมื่อยืดปุ่ม/พาเนล เปลี่ยนสถานะ normal/hover/pressed/disabled ให้แยกได้
- Theme ร่วมกันทั้งเมนู เกมเพลย์ ร้านค้า ภารกิจ สมุดสะสม หน้าผลจับ และ Tutorial โดยรักษาขนาดตัวอักษรและพื้นที่สัมผัส
- ภาพฉากหลัง โลโก้ โมเดลปลา และภาพปลาในสมุดเป็นเนื้อหาเกม ไม่รวมเป็น UI chrome ใน atlas นี้ กราฟิกที่ขยับตามค่าจริง เช่นรอกและโซนแรงตึง รักษาการวาดเชิงโปรแกรมสำหรับข้อมูลที่เปลี่ยนตลอดเวลา
- Atlas ช่วยแชร์ภาพและลดจำนวน resource textures แต่ขนาดไฟล์/VRAM ต้องวัดจริง ไม่ถือว่า atlas ประหยัดกว่าภาพ SVG เดิมโดยอัตโนมัติ

## ขั้นตอน

1. สำรวจ themes, StyleBox overrides, ไอคอน และ control ที่วาดเอง
2. เจนภาพเดียว ตรวจ alpha และขอบเขต sprite จริงก่อนกำหนด region
3. ทำ atlas resources และเปลี่ยน theme/overrides/ไอคอนให้ใช้ atlas ร่วม ปรับ margins ให้รูปไม่ยืดผิด
4. ตรวจ import และ dependency ว่าผิว UI ใช้ PNG เดียว ไม่มีการสร้างสำเนาภาพย่อย
5. เปิดภาพจริงของเมนู ภารกิจ ร้านค้า สมุดสะสม ผลจับ Tutorial และ HUD ที่ 1280×720 กับ 1600×720 ตรวจ contrast ข้อความ การตัดขอบ และความสม่ำเสมอ
6. ทดสอบปุ่ม modal การเลื่อน การรับรางวัล และการควบคุมเดิม แก้แล้วทดสอบซ้ำเฉพาะส่วนที่เกี่ยวข้อง

## เกณฑ์ผ่าน

ผิว UI หลักอ้าง atlas ภาพเดียว สถานะกด/เลือก/disabled ต่างกัน ตัวอักษรไทยไม่อยู่ในภาพ ไม่เสียปฏิสัมพันธ์เดิม ขอบ nine-slice ไม่มี sprite ข้างเคียงรั่ว และภาพจริงทั้งสองอัตราส่วนตรงกับ modern flat

## ผลการลงมือทำ

- เปลี่ยนผิวปุ่ม พาเนล แท็บ ช่องปลา แถบความคืบหน้า พื้นจอย และไอคอน UI ให้ใช้ภาพเจนเดียวแล้ว
- รักษา Theme และ node เดิมให้แก้ต่อใน Editor ได้ เปลี่ยนส่วนที่ override รูปลักษณ์ปุ่มให้ใช้สถานะจาก Theme ร่วม
- ใช้ StyleBoxTexture.region_rect กับ PNG โดยตรง แก้การตัดมุมจากการซ้อน AtlasTexture ใน nine-slice และลด source corner ให้พอดีกับปุ่มมือถือ
- ใช้พื้นผิวที่ไม่มีกรอบประดับสำหรับพาเนล และตัดเฉพาะส่วนทึบกลาง sprite สำหรับ progress bar บาง ๆ
- ภาพ UI เก่าที่ไม่ใช้งานถูกกันออกจาก export presets แต่เก็บต้นฉบับในโปรเจกต์ไว้
