# ค้นหาจ้าวบ่อด้วย minimap

ปรับ 4 พฤศจิกายน 2026

## การเล่น

- แผนที่ใหญ่แสดงภูมิประเทศ จุดยืน ประวัติการจับ จุดโปรด และจุดนำทาง ไม่มีหมุด/มงกุฎ การ์ดข้อมูล หรือ hit target จ้าวบ่อ ทั้งพื้นที่ปัจจุบันและพื้นที่จากเซฟ
- ปุ่มสแกนบน minimap ตรวจปลาจริงในวงรัศมี 100 เมตร ณ เวลากด แสดงผล 6 วินาทีตามค่าเดิม เมื่อหมดเวลาต้องสแกนใหม่ ไม่มีการเปิดเผยจ้าวบ่ออัตโนมัติจากการเดินเข้าระยะ
- ผลที่ตรวจพบติดตามการเคลื่อนไหวของปลาระหว่างช่วงสแกน และซ่อนเมื่อออกนอกระยะหรือถูกจับ เปลี่ยนพื้นที่แล้วล้างผลเดิม
- จ้าวบ่อคือปลาที่หนักที่สุดทั้งบ่อตาม `PondEcosystem.boss()` ไม่ใช่ตัวหนักที่สุดเฉพาะในระยะสแกน หากน้ำหนักเท่ากันใช้ตัวแรกตามกติกาเดิม เมื่อจับตัวนั้นแล้ว ตัวที่หนักที่สุดตัวถัดไปเป็นจ้าวบ่อ; จะปรากฏเป็นทองได้เฉพาะหากอยู่ในกลุ่มที่สแกนพบแล้วและยังอยู่ในระยะ
- หมวดขนาดใช้น้ำหนักจริงแบบเดียวกันทุกสายพันธุ์ ไม่ใช่เปอร์เซ็นต์เทียบกับขนาดสูงสุดของสายพันธุ์

| ระดับ | น้ำหนัก | สี |
|---|---|---|
| เล็ก | น้อยกว่า 1 กก. | ฟ้า |
| กลาง | 1 ถึงน้อยกว่า 5 กก. | เขียว |
| ใหญ่ | 5 ถึงน้อยกว่า 20 กก. | ส้ม |
| มหึมา | ตั้งแต่ 20 กก. | ม่วง |
| จ้าวบ่อ | หนักที่สุดในบ่อ มีลำดับเหนือหมวดขนาด | ทอง รูปเพชรและวงแหวน |

จุดปลามีขอบเข้มและขนาดเพิ่มตามระดับ จ้าวบ่อวาดทับจุดปลาธรรมดาเพื่ออ่านได้เมื่อซ้อนกัน คำอธิบายสีซ่อนเป็นค่าเริ่มต้น กดปุ่ม `?` ข้าง minimap เพื่อเปิด/ปิดได้โดยไม่สแกนหรือเปิดแผนที่ใหญ่ สแกนไม่เปิดแผงให้อัตโนมัติ และผลสแกนหมดเวลาไม่ปิดแผงที่ผู้เล่นขออ่าน เปลี่ยนพื้นที่จะปิดแผง แผงคำอธิบายไม่รับ input เพื่อให้แตะ/แพนฉากผ่านได้

## แก้ใน Godot Editor

- เปิด `features/map/minimap.tscn`: `ScanLegend/Content` เป็น Label จริงครบห้าระดับ จัดด้วย VBoxContainer เปลี่ยนระยะวาง ขนาดตัวอักษร และพื้นหลังได้ใน Editor
- `Content/View.scan_palette` อ้าง `features/map/fish_scan_palette.tres`: ปรับเกณฑ์น้ำหนักและสีใน Inspector ได้จาก Resource เดียว ตอนเริ่มฉากคำอธิบายสีจะอ่านจาก Resource นี้ให้ตรงกับจุดปลา
- `radius_m` และ `scan_duration` บน Minimap กำหนดระยะและอายุผลสแกนเดิม
- เปิด `features/map/fishing_map_panel.tscn` เพื่อปรับแผนที่ใหญ่ ไม่มี BossInfo ในโครงสร้างฉากแล้ว

## การทดสอบ

Godot 4.7.2 Windows ใช้โปรไฟล์ทดสอบแยกจากเซฟจริง:

```powershell
node tools/test_competition.cjs minimap_hunt_visual fishing_map_visual fishing_map_data
```

- `minimap_hunt_visual`: 87 checks ผ่าน รวมปุ่ม `?` เปิด/ปิดแผงแยกจากสแกน ค่าขอบน้ำหนักทั้งสาม การแยกสีและคำอธิบาย การไม่เปิดเผยจ้าวบ่อนอกระยะ/ก่อนสแกน/หลังหมดเวลา การเดินแล้วสแกนใหม่ การเปลี่ยนจ้าวบ่อ การล้างเมื่อเปลี่ยนพื้นที่ และแผนที่ใหญ่ทั้ง 6 พื้นที่ไม่มีช่องข้อมูลจ้าวบ่อ
- `minimap_scan`: 44 checks ผ่านแบบ rendered ผ่านสคริปต์ `tests/minimap_scan_test.gd` รวมวงรัศมี 100 เมตร ตำแหน่ง invalid การติดตามปลา การจับปลา ทัช/เมาส์ เรือ ผลหมดเวลาและแผนที่ขอบพื้นที่
- `fishing_map_visual`: 69 checks ผ่าน แผนที่ใหญ่ ทัช ประวัติการจับ โน้ต จุดโปรด การนำทาง การเปลี่ยนพื้นที่ และการเปิด/ปิดเมนู
- `fishing_map_data`: 43 checks ผ่าน ข้อมูลเก่า การเซฟ/โหลด จุดโปรด ประวัติและการฉายพิกัด
- ตรวจภาพผลห้าสีที่ 960×540, 1280×720 และ 2400×1080 ใน `exports/qa-competition/minimap_hunt_visual/` รวมแผนที่ใหญ่ที่ไม่มีจ้าวบ่อ
- ยังไม่ได้ทดสอบโทรศัพท์จริงหรือเผยแพร่ Android/Web รุ่นใหม่
