## เทียบกับแบบ

| ข้อกำหนด | การตรวจ |
|---|---|
| ใช้บ่อและปลาเดิม | ตรวจชนิดและช่วงน้ำหนักจาก catalog/ประชากรจริง ไม่สร้างปลาเพื่อทำภารกิจ |
| นับทั้งเก็บและปล่อย | ทดสอบเส้นทาง gameplay ทั้งสองแบบ |
| ปลาหนึ่งตัวทำได้หลายข้อ | ทดสอบจำนวน ชนิด น้ำหนัก เหยื่อ ความลึกพร้อมกัน |
| จับปลาตัวเดิมซ้ำไม่ได้ | persistent fish key อยู่ใน snapshot และรายการ seen ของแต่ละภารกิจ |
| เซฟเดิมใช้ต่อได้ | โหลดโปรไฟล์ v1 ที่ยังไม่มี missions และรักษายอดเงินเดิม |
| รับรางวัลครั้งเดียว | ทดสอบกดซ้ำ โหลดใหม่ และแก้ revision แล้วไม่เปิดสิทธิ์รับใหม่ |
| เซฟผิดพลาดไม่จ่ายครึ่งรายการ | จำลอง path ที่เขียนไม่ได้ ตรวจ rollback ทั้งเงิน/สถานะ/ความคืบหน้า และ retry |
| ภารกิจเริ่มหลัง Tutorial | ทดสอบปลาตัวแรกไม่ถูกนับ และไม่เปิดหน้าใหม่ขัดบทสอน |
| เล่นอิสระและหน้าจอไม่รก | HUD ภารกิจซ่อนขณะต่อสู้ กล่องติดตามหนึ่งข้อ และหน้าเปิดปิดคืนสถานะ pause/camera |
| แก้ฉากได้ใน Editor | ตรวจ node ของ panel และ row ก่อนเข้า SceneTree; layout อยู่ใน .tscn ไม่สร้างหน้าจอทั้งหมดในโค้ด |

## หลักฐานทดสอบ

Engine ที่ใช้จริง: Godot 4.7.2 บน Windows, Mobile renderer, D3D12 / NVIDIA GTX 1660 Ti

- `tests/missions_test.gd`: 76 checks ผ่าน รวมทำครบและรับรางวัลครบทั้ง 12 ข้อ เซฟเก่า event ซ้ำ รหัสปลา และ revision
- `tests/missions_visual_test.gd`: รอบสุดท้าย 51 checks ผ่าน รวมเปิดหน้าและรับรางวัลด้วย mouse input ผ่าน Viewport, เลือกระดับ, เลื่อนถึงรางวัลข้อสุดท้าย, pause/camera, catch retry, ผลจับจริงใน gameplay และปุ่มข้ามบทสอน
- Regression suite: import และ 25 ชุดทดสอบ รวม 26/26 entries ผ่าน ดู `exports/qa-missions/regression/results.json` หลังปรับภาพ Tutorial รอบสุดท้าย ตรวจซ้ำเฉพาะ missions_visual (51 checks) และ first_catch_tutorial (0 failures) ผ่าน ดู `visual-console.log` และ `tutorial-console.log` ใน `exports/qa-missions/`
- ภาพจริงที่ 1280×720 และ 1600×720 ตรวจด้วยสายตา อ่านภาษาไทยได้ ปุ่มและแถบความคืบหน้าไม่ตัด รายการข้อสุดท้ายเลื่อนไปถึงได้
- พบปัญหา annotation enum ว่างใน import รอบแรกและแก้ก่อนทดสอบผ่าน; ตรวจภาพ Tutorial แล้วซ่อนปุ่มกระเป๋าระหว่างบทสอนเพื่อไม่ทับการ์ด
- Godot รายงาน `Failed to read the root certificate store` จากเครื่องทดสอบ แยกเป็น host diagnostic ตาม test runner เดิม ไม่พบ script/runtime error ของฟีเจอร์ในรอบที่ผ่าน

ไฟล์ภาพใน `exports/qa-missions/screenshots/`: `missions-tier-0-1280.png`, `missions-tier-2-1600.png`, `missions-tracker-1600.png`, `missions-tutorial-1280.png` และภาพระดับ/สถานะอื่น ๆ

## วิธีปรับและทดสอบซ้ำ

- ปรับชื่อ เงื่อนไข เป้าหมาย และรางวัล: `data/missions/*.tres`
- ปรับหน้ารวม: `features/missions/mission_panel.tscn`
- ปรับการ์ด: `features/missions/mission_row.tscn`
- ปรับปุ่ม/กล่องติดตาม/ข้อความสำเร็จ: `features/fishing/fishing_hud.tscn`
- หากเปลี่ยนกติกาภารกิจเดิมให้เพิ่ม revision: ความคืบหน้าที่ยังไม่รับรางวัลจะเริ่มใหม่เฉพาะข้อนั้น ส่วนที่รับแล้วไม่จ่ายซ้ำ เปลี่ยน ID เฉพาะเมื่อเป็นภารกิจใหม่จริง

รัน `tools/run_tests.py --godot <Godot console executable> --suite all --output exports/qa-missions/regression --timeout 120` เพื่อรวมชุดใหม่กับ regression เดิม runner แยก APPDATA/LOCALAPPDATA สำหรับการทดสอบบน Windows ไม่ใช้เซฟผู้เล่นจริง

## ขอบเขตการยืนยัน
